# Replo Cafe24 storefront

현재 Next.js/React 홈페이지의 핵심 메시지와 디자인 시스템을 카페24 스마트디자인용 HTML/CSS/JavaScript로 변환한 초안입니다.

## 포함 파일

- `index.html`: 카페24 메인 화면에 적용할 랜딩페이지
- `replo-main.css`: 반응형 스타일과 카페24 기본 헤더/푸터 비노출 처리
- `replo-main.js`: 모바일 메뉴, 셀프 진단, 추천 플랜 표시, dataLayer 이벤트

## 적용 위치

카페24 관리자에서 적용할 디자인을 복사한 다음 코드 편집 화면을 엽니다.

1. `cafe24/index.html` 내용을 카페24의 쇼핑몰 메인 `index.html`에 붙여 넣습니다.
2. `cafe24/replo-main.css`를 카페24 디자인 파일 `/css/replo/replo-main.css`로 생성합니다.
3. `cafe24/replo-main.js`를 카페24 디자인 파일 `/js/replo/replo-main.js`로 생성합니다.
4. 메인 페이지 상단의 아래 지시문이 실제 생성한 경로와 일치하는지 확인합니다.

```html
<!--@css(/css/replo/replo-main.css)-->
<!--@js(/js/replo/replo-main.js)-->
```

현재 파일은 기본 레이아웃을 유지하면서 JavaScript로 카페24 기본 헤더·푸터를 숨기고 Replo 전용 헤더·푸터를 표시합니다. 사용 중인 스킨의 기본 요소 ID가 다르면 `replo-main.css` 첫 부분의 숨김 선택자만 조정합니다.

## 판매 상품 등록

메인 요금제 영역은 카페24 `product_listmain_1` 모듈에 연결되어 있습니다. 상품 가격이나 상세페이지 URL을 HTML에 하드코딩하지 않습니다.

카페24 관리자에서 다음 상품을 등록합니다.

| 진열 순서 | 상품명 권장값 | 판매가 | 상품 요약 권장값 |
|---|---|---:|---|
| 1 | Starter / 스타터 | 99,000원 | 월 상담 50건 · 채팅/게시판 · FAQ/스크립트 · 월간 리포트 |
| 2 | Lite / 라이트 | 590,000원 | 월 상담 200건 · 채팅/게시판/이메일 · 데일리 현황 · 월간 리포트 |
| 3 | Basic / 베이직 | 990,000원 | 월 상담 500건 · 전화/채팅/게시판/이메일 · 교환/환불/클레임 운영 |
| 4 | Pro / 프로 | 1,790,000원 | 월 상담 1,000건 · 모든 채널 · CS 정책 설계 · 주간 리포트 |

그다음 `상품 > 상품 진열 > 메인 진열`에서 위 상품 네 개를 **메인 분류 1**에 순서대로 진열합니다. 사용하는 메인 분류의 모듈 번호가 1이 아니라면 `index.html`의 아래 값을 실제 번호로 바꿉니다.

```html
<div class="replo-product-list" module="product_listmain_1">
```

예: 관리자에 표시되는 코드가 `product_listmain_5`라면 HTML도 `module="product_listmain_5"`로 변경합니다.

## 배송 없는 서비스 상품 설정

Replo 플랜은 물리 배송 상품이 아니므로 카페24의 **배송 필요 없음** 설정을 적용합니다. 쇼핑몰 설정에 따라 상품 또는 해당 상품 분류에 일괄 적용할 수 있습니다. 주문서에서 불필요한 배송정보를 받지 않는지 실제 테스트 주문으로 확인합니다.

## 월 자동 결제를 받을 경우

초기 검증 단계에서는 1회 결제로 판매할 수 있습니다. 월 자동 결제가 필요하면 카페24의 **정기배송(정기결제)** 기능을 별도로 신청·설정해야 합니다.

정기결제를 적용할 때는 다음 항목을 함께 확인합니다.

- 사용 중인 PG사가 정기결제를 지원하는지
- 상품 상세와 주문서에 정기결제 디자인이 적용됐는지
- 1회 구매를 병행할지, 정기결제만 허용할지
- 최초 3개월 계약 및 이후 갱신 조건이 상품 상세·이용약관과 일치하는지
- 가격 변경, 해지, 환불, 미납 처리 기준이 명확한지

## 상세페이지 최소 구성

각 플랜 상세페이지에 아래 내용을 반드시 넣습니다.

1. 포함 상담 채널과 월 제공량
2. 초과 건당 비용
3. 운영 시간과 응답 기준
4. 도입 준비 및 운영 시작 일정
5. 고객사가 제공해야 할 계정·정책·권한
6. 최초 계약 기간과 갱신 방식
7. 환불·중도 해지·미납 기준
8. 부가세 포함 여부
9. 포함되지 않는 업무와 추가 비용 발생 조건

## 추천 플랜 표시

JavaScript가 상품명에 `Basic` 또는 `베이직`이 포함된 카드를 찾아 추천 카드로 표시합니다. 실제 상품명이 다르면 `replo-main.js`의 추천 조건을 수정합니다.

## 전환 추적

아래 이벤트를 `window.dataLayer`에 전달합니다.

- `select_plan`: 요금제 상세 버튼 클릭
- `replo_diagnosis_update`: 셀프 진단 선택 변경
- `replo_cta_click`: 주요 CTA 클릭

Google Tag Manager에서 위 커스텀 이벤트를 GA4 및 Meta Pixel 이벤트로 매핑할 수 있습니다. 실제 결제 성과는 카페24 주문 완료 페이지의 구매 이벤트를 기준으로 별도 검증합니다.

## 적용 전 체크리스트

- PC/모바일에서 기본 카페24 헤더가 중복되지 않는지
- 상품 네 개가 실제 관리자 가격으로 표시되는지
- 상품 카드 클릭 시 해당 상세페이지로 이동하는지
- 배송 필요 없음이 주문서에 반영되는지
- 테스트 결제가 정상 완료되는지
- 주문 완료 메일과 관리자 주문 수집이 정상인지
- 부가세, 계약 기간, 환불 조건이 페이지마다 서로 일치하는지
- 결제 완료 이벤트가 GA4/Meta에 중복 전송되지 않는지
